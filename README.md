# DockBar (English)

An LSPosed module that adds a blurred plate behind the dock icons — like on Xiaomi tablets.

## Tested on

HyperOS 2 (Android 14), launcher version 5.39.40.11704-09172004

## Requirements

- Android 12+
- Root (Magisk / KernelSU)
- LSPosed
- POCO Launcher or the system launcher (MIUI Home)

## Install

1. Grab the APK from Releases.
2. In LSPosed enable the module and set the scope to POCO Launcher / system launcher.
3. Reboot your phone.
4. Open the app, tweak the settings and hit "Apply".
